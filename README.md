# Сообщения об обновлении сервера 1С

Генератор текстов для рассылки коллегам о плановых работах на сервере 1С.

**Открыть:** https://imiron.ru/1c-update-messages/

Задаёте дату, время начала и длительность — страница сама собирает три
готовых сообщения:

1. **Предупреждение** — за день или утром в день работ
2. **Начало работ** — в момент старта
3. **Работы завершены** — после окончания

Даты и длительность склоняются по-русски («около 1 часа 30 минут»,
«сегодня», «в пятницу»), время окончания считается автоматически.
Контакт поддержки и ссылка на платформу запоминаются в браузере.

Каждое сообщение копируется в один клик — обычным текстом, с форматированием
для почтовой рассылки или только тема письма.

Страница статическая, без зависимостей и серверной части: работает локально,
если скачать `index.html`.
